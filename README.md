# 蜜境研究站

Three.js 第一人稱雙語閱讀遊戲，適合高中職學生。保留原有十項任務與兩組密碼，新增第十一項棲地與威脅測驗。

## 啟動

在此資料夾執行 `node server.mjs`，瀏覽 http://localhost:4173。也可部署到 GitHub Pages，讓手機與 iPad 直接用瀏覽器開啟 HTTPS 網址；設定方法見下方「GitHub Pages」。不要直接以 file 協定開啟 HTML。

電腦按滑鼠左鍵切換前進，再按一次停止；也可用 WASD／方向鍵移動，拖曳環視，E 互動，M 開地圖，Esc 關閉面板。手機／iPad 用左側觸控方向盤移動、右側拖曳環視，到站後按 Observe 開啟任務。地圖顯示關卡進度；需依箭頭自行走到目前觀察站才能開始作答。已完成任務可在研究手冊重讀。

每關分成「閱讀線索 → 完成挑戰 → 通關」三個步驟。作答時可返回教材，保留原有輸入與選項；看圖題會保留參考圖。答對後會顯示下一站提示與箭頭；關閉面板後自行前往，抵達觀察站再按 Observe 開啟任務。進度與所在位置會定期存入目前瀏覽器，重新開啟可接續。

十一關依序解鎖。答錯不解鎖，答對取得密碼或棲地徽章，並顯示下一站指示。畫面上方的方向箭頭配合地面金色箭頭引導行走，路線使用 A* 避開場景障礙物。完成全部十一關後，在出口輸入兩道密碼。舊版進度僅保留從第一關起連續完成的部分。進度只儲存在目前瀏覽器的 localStorage，可從研究手冊清除。不會跨裝置同步，也沒有教師端或防作弊系統；客戶端程式含判分資料。

## 視覺更新

蜜蜂具有分節收尖腹部、六隻關節腳、兩對薄翅與翅脈、複眼、觸角與胸部短毛。飛行蜜蜂會拍翅。第 3、7 關提供可拖曳旋轉與放大縮小的獨立 3D 模型觀察台。

樹木使用漸細分枝、立體分布的實例化葉片和樹皮紋理；場景調整日光與天空補光，加入地面紋理與局部接地陰影。模型仍是程序化教學示意，並非生物學精確掃描。

以 `node --test tests/*.test.mjs` 執行關卡解鎖、舊進度遷移、避障與不可達路線測試。

## 流暢度與畫質

右上角可選自動、省電、精緻三種畫質。自動模式依觸控裝置調整初始像素比例，持續低幀率時降低解析度；省電模式停用即時陰影，仍保留接地陰影。即時陰影以較低頻率更新，閱讀與歡迎畫面暫停背景動畫與繪圖。重複蜜蜂共用幾何與材質，遠景葉片減量，路線只在需要時重算，使用最小堆積處理 A* 搜尋。

第 3、7 關的近距離模型按需載入，重用同一個觀察台，只在旋轉、縮放或尺寸變化時繪圖。主畫面合併任務提示，避免大面板遮住行走視野。

互動節奏參考使用者提供的 https://ijun-ai.com/chinese/bird-liang/app/ ，取其精簡任務提示、操作說明與分段閱讀概念；保留本專案教材、蜜蜂農場場景與答對才解鎖的規則。

## 教材與資源

內容依專案的《認識蜜蜂_中英雙語》《蜜室逃脫_學生任務本》《蜜室逃脫_教師解答》。第九、十關使用原有 MP3，答對才顯示逐字稿。新增第十一關依第八節，選出種植適合當地的開花植物、保護棲地兩個行動。

背景音使用使用者指定的站長素材「自然环境野外蜜蜂音效」，來源：https://sc.chinaz.com/yinxiao/230802189700.htm 。來源頁標示僅供學習與參考、勿用於商業用途；詳細來源記錄位於 dist/assets/AUDIO-SOURCE.md。音檔保存在專案中，點擊開始探索後循環播放，可從畫面右上角開關，設定會儲存在目前瀏覽器。進入第 9、10 關聽力時會暫停背景音，離開後恢復；切換到其他分頁時也會暫停。

3D 模型與圖像為簡化教學示意，非等比例，並非生物學精確模型。場景採真實農場配置搭配程序化模型；遠景使用 ImageGen 生成的寫實樹林全景，提示與來源記錄於 forest-background-source.md。Three.js 0.170.0 存於 dist/vendor，依 MIT 授權。Google 字型為可選網路載入，無網路會使用系統字型。

公開教學使用前請用實際手機／iPad 測試效能、觸控與聽力播放。線上私有部署需擁有者登入，學生共用請另行設定適合的存取方式。

## 過關證書

完成十一項任務並解開出口後，可輸入姓名領取過關證書，下載 1600 × 1130 PNG 或以 A4 橫向列印／存成 PDF。證書與日期保存在目前瀏覽器，也可從研究手冊重新開啟、修改姓名。清除本機進度會同步清除證書。

## GitHub Pages

此專案含 `.github/workflows/deploy-pages.yml`，推送 `main` 後會自動將 `dist/` 部署到 GitHub Pages。建立 GitHub 儲存庫後，請到 **Settings → Pages** 將來源設為 **GitHub Actions**；第一次成功部署後，GitHub Actions 會顯示網站網址。靜態資源使用相對路徑，可部署在使用者／專案頁面路徑下。

手機與 iPad 可直接用 Safari／Chrome 開啟 Pages 網址；支援觸控方向盤、拖曳環視、畫質自動調整。遊戲進度保存在各裝置的瀏覽器，不會跨裝置同步。
